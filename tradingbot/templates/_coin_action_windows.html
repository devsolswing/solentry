{# Coin action windows: Send / Receive / Buy / Sell, each in its own popup window over the coin detail page. The forms are the same ones the coin popup and the wallet send page already use — same endpoints, same guards (paper ledger for paper, pump.fun executor with the bot's limits for real, two-step confirm for sends). Every action ends on a confirmation stating the result, with a way back to the coin page. Expects: coin (row), bots, mode ('paper' or 'devnet'), mode_label, receive_address, coin_network (which chain the coin lives on), send_refusal (plain refusal when the coin is not a Solana asset, else None), network_label ("Solana (devnet)"). The Send and Receive windows account for the network: a Solana coin shows the network it will use in plain words; a coin that lives on another chain is refused plainly — its address is never shown and no send form is rendered, so nothing can be sent on the wrong network. #}
