{# Trenches quick-buy receipt popup + the delegated one-tap handler (buy-flow batch 6, James 2026-11-27 ~07:32-07:41). Included by trenches.html and dashboard.html — both render trenches badges. How it works: each badge's Buy 1 / Buy 2 / Sell All Now form submits normally without JavaScript (plain result page). With JavaScript, this handler intercepts the submit, posts the same form with format=json, and: - a bought coin opens this receipt popup with the full details (amount, coins, price, signature + Solscan link, signing bot, venue, SOL spent, priority-fee price/cap, new balance); - a sold coin does NOT get a receipt popup (none was ordered) — the button row is replaced by a short "Sold" line and the list refreshes so Sell All Now disappears; - a refused trade opens the popup with the plain reason instead (heading + lines from the server, never a guessed error). Every value is set with textContent, never innerHTML — coin names come from the feed and are never trusted as markup. #}
